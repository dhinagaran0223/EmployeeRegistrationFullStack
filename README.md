# Employee Registration - .NET 8 Web API + Angular + SQL Server

This implementation follows every requirement in the supplied assignment PDF:
- Employee Id generated by database and non-editable
- Mandatory: Employee Name, Age, MobileNum, Address Line 1, Pincode, State, Country
- Optional: Date of Birth, Address Line 2
- DOB date picker; future dates rejected; DOB automatically calculates Age
- Employee Name: alphabets only
- Age: numeric, 1–3 digits
- Mobile: exactly 10 digits and unique; duplicate gives the required message
- Address lines reject $, %, !, +
- Pincode: exactly 6 digits
- Country/State are linked in both directions
- Employee grid shows Id, Name, Mobile, Age
- Pagination: 5 records per page
- Filters: Employee Name and Mobile
- Edit and delete
- Delete confirmation
- REST CRUD APIs: Create, Get list/detail, Edit, Delete
- SQL Server tables: Country_Mst, State_Mst, Employee_Mst with PK/FK relationships

## Prerequisites
- .NET 8 SDK
- Node.js 20+ and npm
- Angular CLI: `npm install -g @angular/cli`
- SQL Server Express/Developer/LocalDB
- VS Code

## Database
The API is configured for SQL Server LocalDB by default.

1. Open SQL Server / LocalDB.
2. The API creates the database/tables and seeds India/USA/UK + sample states on first run.
3. If you want an explicit SQL script, see:
   `backend/EmployeeRegistration.Api/Database/EmployeeRegistration.sql`

If you use SQL Server Express instead of LocalDB, change the connection string in:
`backend/EmployeeRegistration.Api/appsettings.json`

## Run backend
```bash
cd backend/EmployeeRegistration.Api
dotnet restore
dotnet run
```

Swagger:
`http://localhost:5000/swagger` or the HTTPS URL printed by `dotnet run`.

## Run Angular
In another terminal:
```bash
cd frontend/employee-registration
npm install
ng serve
```

Open:
`http://localhost:4200`

## API endpoints
- POST   `/api/employees`
- GET    `/api/employees?pageNumber=1&pageSize=5&name=&mobile=`
- GET    `/api/employees/{id}`
- PUT    `/api/employees/{id}`
- DELETE `/api/employees/{id}`
- GET    `/api/countries`
- GET    `/api/countries/{countryId}/states`
- GET    `/api/states/{stateId}/country`

## Validation design
Client-side Angular validation provides immediate feedback.
Server-side ASP.NET validation repeats the business rules so invalid requests cannot bypass the UI.
The database has a unique index on MobileNum as a final duplicate-protection layer.
